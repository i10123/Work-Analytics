# Work Analytics — Система анализа ИТ-рынка труда

**Work Analytics** — это современное веб-приложение для автоматизированного сбора, агрегации и визуализации данных о вакансиях в сфере ИТ. Проект разработан как инструмент для статистического анализа рынка труда, позволяющий отслеживать тренды по зарплатам, востребованным навыкам и опыту работы.

---

## 🌟 Основные особенности

*   **Мультиисточниковый парсинг**: Сбор данных с крупнейших площадок:
    *   **HH.ru** (через официальный API).
    *   **Rabota.by** (через API).
    *   **Хабр Карьера** (через парсинг HTML с механизмами защиты от блокировок).
*   **Real-time обновления (SSE)**: Использование Server-Sent Events для мгновенного уведомления фронтенда о прогрессе и завершении фоновых задач парсинга.
*   **Умная работа с валютами**: Автоматическая конвертация зарплат в единую валюту для корректного построения графиков через внешнее API (ExchangeRate-API) с надежной системой fallback (резервных курсов).
*   **Zero-DB Архитектура**: Полное отсутствие классических СУБД — все данные сохраняются и обрабатываются в структурированном формате JSON, что упрощает деплой и делает проект максимально прозрачным.
*   **Премиальный UI**: Интерфейс на чистом Vanilla CSS с поддержкой динамических тем (Deep Aqua Ember, Solar Coral, Neutral Slate), современным стеклянным дизайном (Glassmorphism) и интерактивными графиками на Chart.js.
*   **Академическая чистота**: Код полностью задокументирован с использованием JSDoc и снабжен подробными логами каждого этапа работы, что идеально подходит для защиты курсового проекта.

---

## 🛠 Технологический стек

*   **Backend**: Node.js, Express.js.
*   **Parsing**: Axios, Cheerio.
*   **Frontend**: Vanilla JavaScript (ES6+), Vanilla CSS (Flexbox/Grid, CSS Variables).
*   **Charts**: Chart.js.
*   **Storage**: File System (хранение в `/data/reports/*.json`).
*   **Integration**: ExchangeRate-API, Gemini API (для интеллектуального извлечения навыков).

## 🚀 Быстрый запуск

### 1. Подготовка окружения
Убедитесь, что у вас установлен **Node.js** (рекомендуется v18+).

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневом каталоге и добавьте необходимые ключи (см. `.env.example`, если доступен):
```env
PORT=3000
# Поддерживается ротация нескольких ключей (через запятую)
GEMINI_API_KEYS=your_key_1, your_key_2
EXCHANGE_RATE_API_KEYS=your_key_here
```

### 4. Запуск приложения
```bash
# Режим разработки (автоперезагрузка сервера)
npm run dev

# Обычный запуск продуктовой версии
npm start
```
Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

## 📊 Основные функции UI

1.  **Интерактивный Дашборд**: Визуализация распределения зарплат, топ-навыков (Word Cloud/Bar Charts) и структуры опыта.
2.  **История Отчетов**: Просмотр и сравнение ранее созданных срезов рынка труда.
3.  **Конфигуратор Сбора**: Тонкая настройка ключевых слов, регионов и глубины парсинга (лимит вакансий).
4.  **Система Тем**: Динамическая смена визуального стиля без перезагрузки страницы.
5.  **Панель Состояния**: Мониторинг фоновых процессов через анимированный индикатор выполнения.

## 📝 Разработка и стандарты

Проект следует строгим правилам оформления (**Code Guidelines**):
*   **JSDoc**: Каждая функция содержит описание параметров `@param` и возвращаемых значений `@returns`.
*   **Logging**: Детальное логирование в консоли с логическими префиксами `[Parser]`, `[API]`, `[Storage]`.
*   **Safe Parsing**: Учет лимитов (1-2 сек задержки) при парсинге HTML-страниц во избежание блокировок IP.
