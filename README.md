# 📊 Work-Analytics

Интеллектуальный агрегатор и анализатор IT-вакансий с интеграцией LLM для сбора и глубокого анализа навыков, зарплат и трендов рынка труда.

## 🚀 Быстрый старт

1. **Установите зависимости**:
   ```bash
   npm install
   ```

2. **Настройте переменные окружения** (создайте файл `.env` в корне проекта):
   ```env
   PORT=3000
   HH_CLIENT_ID=your_id
   HH_CLIENT_SECRET=your_secret
   EXCHANGE_RATE_API_KEYS=your_exchange_keys
   ```

3. **Запустите приложение**:
   ```bash
   npm run dev
   ```
